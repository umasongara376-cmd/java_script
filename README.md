# JavaScript Fundamentals

A collection of small JavaScript examples for practicing core language concepts. The repository is organized as individual `.js` files so examples can be read and run independently.

## Topics Included

The visible files cover concepts such as:

- Arrays and array indexing
- Arrow functions
- Conditional logic
- Data types and variables
- Array filtering
- Functions
- Mapping and object literals

## Requirements

- Node.js, or a modern browser's developer console
- A text editor or IDE

## Run an Example with Node.js

From the repository root, run a JavaScript file by name:

```bash
node array.js
node arrow_function.js
node functions.js
```

Use the filename you want to explore. Some examples may rely on console input/output or may simply print demonstration values.

## Suggested Learning Approach

1. Read one file at a time.
2. Predict the output before running it.
3. Change sample values and compare the output.
4. Add a short comment explaining the concept you learned.

## Note

This repository is a learning collection rather than a packaged application; no build step is required for the standalone examples.
